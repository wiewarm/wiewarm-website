# Agent commits

Always include a `Co-authored-by:` trailer identifying the contributing agent in
every commit created by an agent, including documentation-only commits.

For Codex, use:

```text
Co-authored-by: Codex <noreply@openai.com>
```

Other agents should use their own name and co-author email. Preserve any existing
co-author trailers when amending a commit.
